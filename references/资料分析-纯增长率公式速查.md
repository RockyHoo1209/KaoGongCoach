# 资料分析 · 纯增长率公式速查

> 不需要绝对量，只用增速就能算。考场优先识别。

---

## 1. 平均数增长率 ⭐⭐⭐⭐⭐

```
平均数增长率 = (a - b) / (1 + b)
```

| 场景 | a（分子增速） | b（分母增速） |
|------|-------------|-------------|
| 人均收入 | 总收入增速 | 人数增速 |
| 亩产 | 总产增速 | 面积增速 |
| 均价 | 总额增速 | 数量增速 |
| 单位成本 | 总成本增速 | 产量增速 |

**结果带 %**，不是百分点。

---

## 2. 比重增速（比重变化率）= 平均数增长率 ⭐⭐⭐⭐

```
比重增速 = (a - b) / (1 + b)
```

与平均数增长率是**同一公式，不同含义**：
- 平均数增长率 → 结果意为「平均数涨了 X%」
- 比重增速 → 结果意为「占比本身涨了 X%」

**⚠️ 不要和两期比重差混淆：**
- 比重增速 = (a-b)/(1+b) → 结果带 **%**
- 两期比重差 = (A/B)×[(a-b)/(1+a)] → 结果带 **百分点**

---

## 3. 间隔增长率 ⭐⭐⭐⭐⭐

```
r = r₁ + r₂ + r₁ × r₂
```

已知相邻两年/两期增速，求跨期总增速。

**考场技巧：**
- r₁ 和 r₂ 都 ≤ 10% 时，乘积项可忽略，直接 r ≈ r₁ + r₂
- r₁ 或 r₂ 较大时（≥ 10%），乘积项必须保留

---

## 4. 乘积增长率 ⭐⭐⭐

```
R ≈ a + b + a × b
```

当 **总量 = 因子A × 因子B** 时适用：

| 场景 | 总量 | 因子A | 因子B |
|------|------|-------|-------|
| 总产 = 面积 × 亩产 | 总产增速 | 面积增速 | 亩产增速 |
| 收入 = 单价 × 销量 | 收入增速 | 单价增速 | 销量增速 |
| 总成本 = 单位成本 × 产量 | 总成本增速 | 单位成本增速 | 产量增速 |

---

## 5. 比重趋势判断（定性）⭐️⭐️⭐️⭐️⭐️

```
比重上升 ⇔ a > b
比重下降 ⇔ a < b
比重不变 ⇔ a = b
```

不需要任何绝对值，只看两个增速谁大。

---

## ⚡ 考场四步判

| 问题问法 | 用哪个 | 纯增速？ |
|---------|--------|:-------:|
| 「增长了百分之几」+ 平均数/比重 | **① 或 ②** | ✅ |
| 「提高了多少个百分点」| **两期比重差**（需 A/B） | ❌ |
| 「两年累计增长」 | **③ 间隔增长率** | ✅ |
| 「总产增速 / 收入增速」 | **④ 乘积增长率** | ✅ |
| 「比重上升还是下降」 | **⑤ 定性判断** | ✅ |

---

## 📌 速记口诀

> **均增=比重增，都是 (a-b)/(1+b)**  
> **间隔 r₁+r₂+r₁r₂，乘积也是 a+b+ab**  
> **升降只看 a>a>b，纯增速一步判**
