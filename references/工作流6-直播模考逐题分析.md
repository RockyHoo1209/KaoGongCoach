# Workflow 6：直播模考逐题分析

> 在 exam-mistake-manager SKILL.md 中用此路径引用：
> `└─ 直播模考逐题分析 → references/工作流6-直播模考逐题分析.md`

---

## 触发条件

- 用户连续发送模考（模考大赛）截图，每张截图一道错题
- 截图包含：图表/材料 + 题干 + 选项（含用户选择 + 正确答案标记）
- 用户消息为简洁指明（如"这道题呢"）或直接发送截图

---

## 核心流程

对每张截图执行以下 **5 步**：

### Step 1：截取关键信息

| 检查项 | 问什么 | 为什么要问 |
|--------|--------|-----------|
| 图表标题 | "累计"还是"当月"？ | 累计值必须做差才能用 |
| 图表类型 | 折线/柱状/表格？数值轴和增速轴各是什么？ | 分清哪个是量哪个是率 |
| 题干问法 | 同比/环比？增速/增量/比重/贡献率？ | 不同问法对应不同公式 |
| 选项 + 用户答案 | 用户选了什么、正确答案是什么？ | 锁定错因方向 |
| 答案解析 | 解析的思路是什么？ | 学到正确的思考路径 |

### Step 2：定位考点 + 识别错因

**考点映射（高频考点速查）：**

| 题干特征 | 对应考点 | 速查表章节 |
|---------|---------|-----------|
| "环比增速高于上年同期" | 由同比判断环比比大小 | 十二 |
| "比重上升/下降" | 比重趋势（比重上升=部分增速>整体增速） | 四 |
| "利润率变化反推利润增速" | 两期比重逆用 | 四 |
| "增长贡献率" | 增长贡献率≠现期占比 | 五 |
| "累计数据+环比" | 读图第一眼→累计先做差 | 十四 |
| "增速比较" | 看比重折线趋势，不计算 | 十三 |

**错因归类（预置词库）：**

| 错因类型 | 示例 | 应对 |
|---------|------|------|
| 概念混淆 | 贡献率≠占比、同比≠环比、累计≠当月 | 回到定义，区分分子分母本质 |
| 公式不熟 | 两期比重/平均数增长率公式盲区 | 补公式速查表 |
| 计算失误 | 截位/尾数/估算放缩错误 | 看选项差距再定估算精度 |
| 审题偏差 | 问增速答增量、问环比看同比 | 题干关键词圈画 |

### Step 3：入库错题

```python
# 创建错题
mistake_manager.create_mistake(
    question_type="资料分析",
    knowledge_point="增长贡献率",
    error_reason="概念混淆——现期占比（总量÷总量）≠ 增长贡献率（增量÷增量）",
    correct_answer="A",
    source="2026下半年省考第十一季行测模考大赛"
)

# 更新索引
index_manager.add_entry(...)
```

### Step 4：检查并同步公式速查表

1. 加载技能库的 `references/资料分析-公式速查.md`
2. 若该考点/推论的速查表章节不存在 → 立即追加写入
3. 同时检查用户的实际文件（`/mnt/e/obsidianNote/考公/参考书籍/资料分析常用公式速查.md`）是否已有该内容，若没有则同步更新

### Step 5：给出针对性口诀

- 必须包含可行动的"**停一步**"规则
- 必须与用户历史错题中相同考点产生连接（"这次和错题-XXX是同一类"）

## 用户偏好嵌入

> 以下为该用户在实测中反复验证的偏好，每次执行本工作流时必须遵守：

1. **必须包含口诀/停一步规则** —— 每条分析末端都要有一行可背诵的触发规则
2. **概念混淆类错题必须突出"本质区分"** —— 用一句话说透两个概念的分子分母差异
3. **直接聚焦** —— 不展开过多背景，5-8 行收尾
4. **与历史同类错题连接** —— 让用户看到系统性薄弱点，而不是孤立错题
