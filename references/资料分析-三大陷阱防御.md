# 资料分析·三大陷阱防御

> 源自 2026-07-14 实战诊断：难度4.0只拿到4成准确率，三大失分原因。
> 每个陷阱配合一条可背诵口诀 + 一个「停一步」触发规则。

---

## 总览

| # | 陷阱类型 | 出题手法 | 停一步规则 |
|:-:|:---------|:---------|:-----------|
| ① | **句式陷阱** | 选项句式完全一致，偷换分母/对象/年份 | 逐项检查三要素：分母✅ 对象✅ 年份✅ |
| ② | **计算错误** | 多位小数 + 单位混用（亿/万混给） | 截位→保分数→复查÷×方向→统一单位再算 |
| ③ | **图表对应错误** | 多条线对应不同坐标轴，看串行/看错年份 | 先扫几条线几个轴→笔指着读→口头复述 |

## ① 句式陷阱

### 典型手法

在同一组选项中，前两项长得很像（同一格式），第三项突然改了分母/对象/时间范围，但句式雷同让人惯性统一处理。

### 真题案例（用户 2026-07-14 实战）

> 下列指标中，2019 年的数值高于 2018 年的有几项？
>
> ① 固定数据及互联网收入占**电信业务收入**比重
> ② 移动数据及互联网收入占**电信业务收入**比重
> ③ IPTV 收入占**固定增值业务收入**比重 ← ⚠️ 分母变了！

①②分母=总收入1.31万亿（增速0.8%），③分母=固定增值1371亿（增速21.2%）。
IPTV 增速21.1% < 固定增值增速21.2% → 比重下降，不是上升。

### 停一步规则

> **「看似同类，逐个检查——分母是不是同一个？对象是不是同一个？年份是不是同一个？」**

### 考场口诀

```
选项排排站，三步逐个看：
分母✅ 对象✅ 年份✅
三项全同再比较，一项不同单独判。
```

## ② 计算错误

### 常用手法

- 给多位小数让你硬算，选项差距小
- 单位混用（亿元/万元/元混着给，不换算直接算）
- ÷×方向搞反

### 防御流程

```
① 先看选项差距
   差距大 → 估算（截2位）
   差距小 → 精算（截3位）

② 分数保分数
   7/8 保持分数形式，不化成 0.875

③ 复查÷×方向
   算完回头看一眼：除以还是乘以？方向有没有反？

④ 单位统一
   全变亿 / 全变万，同级再算
```

### 考场口诀

```
选项差距大就估，差距小才精算；
分数保持不化小，÷×方向回头瞧；
单位统一到同级，百分号不离手！
```

## ③ 图表对应错误

### 常见失误

| 场景 | 错误表现 | 正确做法 |
|:----|:---------|:---------|
| 双纵轴 | 对着左轴读右轴数据系列的值 | 先看图表有几条线，各对应哪个轴 |
| 多行多列表格 | 看串行 / 看错列 | 笔尖点着数据格逐行移动 |
| 折线+柱状组合 | 用折线增速当数值，或反之 | 确认纵轴单位和图例标注 |

### 停一步规则

> **「用手指/笔尖指着数据点读一遍，读完口头说一遍结论。」**

把结果说出声能拦截 80% 的看错——大脑听到自己说的数字会触发校对。

### 考场口诀

```
扫图三件事：几条线？几个轴？图例在哪？
读数用笔指，结论说出声。
```

## 做题前自检清单（7项）

每次开始资料分析专项前，默念一遍：

```
___________________________________
|  做题前逐一核查：                  |
|                                   |
| □ ① 标题是"累计"还是"当月"?        |
| □ ② 问的是"同比"还是"环比"?        |
| □ ③ 数据是"数值"还是"增速"?        |
| □ ④ 有没有"月均/日均/年均"?        |
| □ ⑤ 问的是"几倍"还是"多几倍"?      |
| □ ⑥ 选项句式一致？检查分母/对象/年份 |
| □ ⑦ 图表几条线？各对应哪个轴？       |
|___________________________________|
```

## 资料分析六句诀

| 口诀 | 对应陷阱 |
|:----|:---------|
| **百分号不离手** | 算完 0.9% 不能写成 0.9 |
| **分数保分数** | 7/8 保持不化成 0.875 |
| **多几倍必减1** | A 比 B 多几倍 = A/B − 1 |
| **看见"率"字停一步** | 是增长率还是贡献率？同比还是环比？ |
| **累计做差再用** | 累计不是当月，先减前一期 |
| **比重升降只看增速大小** | a > b → 升，不用算 |
