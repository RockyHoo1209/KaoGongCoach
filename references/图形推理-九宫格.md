# 图形推理 — 九宫格题型方法论

> 来源：用户实战错题总结 + 公考知识库「图形推理方法论」

## 九宫格排查顺序（强制流程）

拿到九宫格题，按以下优先级系统排查，**不要凭感觉在格子间来回跳**：

| 优先级 | 排查维度 | 怎么看 | 命中信号 |
|:---:|------|------|------|
| 1 | 横行遍历 | 每行三格看成一个整体——元素种类是否遍历？（每行每种元素各出现一次） | 每行元素种类齐全、不重复 |
| 2 | 横行位置 | 同行内，元素位置怎么移动？（平移/旋转/翻转） | 同行内位置有规律变化 |
| 3 | 横行数量 | 同行内，某元素数量递增/递减？（点线面角素） | 数量变化呈等差/等比 |
| 4 | 竖列规律 | 如果横行不通，换竖列看 | 竖列有遍历/移动/数量规律 |
| 5 | 对角线 / 米字型 / S型 | 最后手段，极少考 | 对角线对称、蛇形读取 |

## 典型题型速判

### 题型一：样式遍历 + 位置旋转（双层规律）

**特征**：每格有多个属性（内部图案 + 外部元素 + 位置），每行看过去每种属性值都出现一次。

**解法**：
1. 先做遍历：每行缺哪种内部图案？缺哪种外部元素？→ 问号处补上
2. 再做位置：同行内位置怎么转？→ 顺时针/逆时针，每次转多少度
3. 合并：内部图案 + 外部元素 + 方位 → 唯一答案

**典型错因**：只看了遍历没看位置，或者盯着单个格子拆着看，没把一行三格打包。

### 题型二：叠加/去同存异

**特征**：前两格叠加后得第三格（或去同存异/去异存同）。

**解法**：同行/同列看前两格如何运算得第三格。**先判方向（行还是列），再做运算。**

### 题型三：对称/旋转

**特征**：每格图形有方向性，同行/同列方向有规律变化。

**解法**：看箭头、开口、对称轴方向的变化模式。

## 考场速记

```
九宫格，先横看，遍历位置数量判。
遍历不全补元素，位置不对找旋转。
横行不通换竖列，对角米字最后看。
整体思维别拆格，规律两层叠着办。
```
