# 图形推理 — 通用入口决策树 + 高频错因

> 来源：用户实战错题总结（2026年7月多次入库 错题-270~273）

## 入口决策树（第一眼判断顺序）

拿到图形推理题，**不要凭感觉在几个方向之间来回试**。按以下顺序做一次系统排查：

```
元素组成相同  → 位置规律（平移/旋转/翻转）
    ↓（不同）
元素组成相似  → 样式规律（加减同异/遍历）
    ↓（不同）
元素组成不同  → 属性规律（对称/曲直/开闭）
                 ↓（无属性规律）
                 数量规律（点/线/角/面/素 + 复合）
    ↓（特殊图形）
特殊类        → 空间类（展开图/三视图/截面图/立体拼合）
```

### 口诀（考场用）

```
相同找位置，相似看样式，
不同先属性，属性无就数。
复合规律多，两维同时看。
特殊题不慌，展开三视图。
```

## 常见规律速判特征

| 规律大类 | 子类 | 特征信号 |
|---------|------|---------|
| 位置 | 平移 | 元素相同，位置在变 |
| 位置 | 旋转 | 元素相同，方向在变 |
| 位置 | 翻转 | 镜像对称感 |
| 样式 | 加减同异 | 元素相似，线条重复出现 |
| 样式 | 遍历 | 九宫格每行元素种类齐全 |
| 属性 | 对称 | 轴对称/中心对称感 |
| 属性 | 曲直 | 全曲/全直/曲直混合 |
| 属性 | 开闭 | 封闭/开放图形 |
| 数量 | 点/线/角/面/素 | 元素组成不同且无属性规律 |
| 数量 | 复合 | 两个数量维度同时满足（如部分数=黑球数） |
| 空间 | 三视图 | 给出两个视图求第三个 |
| 空间 | 展开图 | 面的相邻关系 |
| 空间 | 截面 | 立方体被切一刀 |

## 题型专项突破

### 1. 七去一/九去一题型（选一个去掉后剩下有规律）

**特征**：题干给7个或9个图形，问去掉哪个后剩下图形呈现规律。

**突破口**：做**相邻两图的逐线逐素比较**。
- 差1根线 → 位置平移规律
- 差更多 → 其他规律

**典型错因**：没做相邻比较，直接去看整体对称/遍历等，找不到方向。

### 2. 三视图题（左视图+主视图→俯视图）

**关键操作**：必须用**方块总数验证**俯视图候选。
- 大立方体总格数 = 长×宽×高
- 已知方块数 = 白+灰+黑（题干给出）
- 推导空格数 → 每个候选俯视图必须产生相同数量的空格

**典型错因**：只靠空间想象推形状，漏了计数验证。三视图的本质是「形状+数量」双重约束。

### 3. 样式规律 + 旋转的组合

**特征**：图1和图2先做加减同异运算，再旋转得到图3。

**解法**：
1. 前两图求异/求同 → 得到中间图
2. 中间图旋转 → 得到图3
3. 验证第二行再用一次

**典型错因**：只做了加减同异，忘了还有旋转这一步。双层规律只看了一层。

### 4. 曲直性专项（九宫格按行分布）

**特征**：元素组成不同，无明显对称/开闭特征，但曲直感明显（全曲线/全直线/混合）。

**高频规律**：九宫格按行分配曲直属性
- 第一行：全曲线图形
- 第二行：曲直混合图形
- 第三行：全直线图形（或反向递进）

**解题动作**：
1. 元素组成不同 → 先走属性规律（曲直/对称/开闭），不要直接跳数量
2. 九宫格优先看横行 → 判断每行内部曲直属性是否统一
3. ？处继承同行的曲直属性

**典型错因**：看到元素组成不同就直接进入数量排查，跳过属性规律排查。

### 5. 数量复合规律

**特征**：图形中的元素有两个以上变化维度。

**解法**：同时列出两个维度的数据序列，找等量/等差关系。
- 例：部分数序列 [2,1,4,3,3] + 黑球数序列 [2,1,4,3,3] → 部分数=黑球数

**典型错因**：只盯一个维度，没把两个序列并排对比。

## 整体建议

1. 每道题先按入口决策树**走一遍流程**（不要跳步骤）
2. 数量规律一定要把复合（两维并行）作为常规思路
3. 三视图和七去一这类非标准题型，先看特征再选方法
4. 图形推理没有「捷径」——只有系统排查 + 积累常见规律类型
